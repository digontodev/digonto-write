Digonto Write 1.0
=================
A word processor in the style of Word, Google Docs and LibreOffice Writer.

Styles (Title, Headings 1-4, Quote, Code), fonts, sizes, bold/italic/underline/strike, sub/superscript, colors, highlight,
alignment incl. justify, bulleted and numbered lists with levels (Tab / Shift+Tab), line and paragraph spacing, tables
(insert, add/remove rows and columns, merge/split, shading, borders), pictures, links, page breaks, find and replace,
navigation pane of headings, page setup (paper, orientation, margins, header and footer with page numbers), word count, zoom.
Files: open DOCX, ODT, HTML, Markdown, text. Save DOCX, ODT, HTML, Markdown, text, PDF. Print.

Limits in this version: on screen the sheet is one continuous page with dashed page-break lines (margins, header and footer are
applied per page in PDF, print and DOCX). Spell check: English (red wavy line; right-click for suggestions, F7 next mistake). Comments, tracked changes,
footnotes, text boxes and equations are not supported.
Tested here without a real screen; please report bugs after your own testing.
Only PySide6-Essentials is installed, locked with SHA-256 hashes.

Start screen: opens with New / Open on the left and your recent files on the right. Open has tabs (This computer, Recent, Shortcuts). Ctrl+W returns to the start screen; the program asks before closing a document with unsaved changes.
